First public release of QUARZ, the quasi-static particle-in-cell code for plasma wakefield acceleration on arbitrary non-uniform radial grids, described in [arXiv:2610.16910](https://arxiv.org/abs/2610.16910).

QUARZ is a **zero-touch code**: all of its source code, tests and documentation were written by an AI agent (Claude, Anthropic) directed by A. Pukhov, who did not write a line of the code. Correctness rests on 21 validation sections against independent analytic and numerical references (`validation/`, README §7).

**Highlights**
- RZ geometry with azimuthal modes m = 0, 1 on any monotone radial grid: exact discrete Gauss law, exact uniform-plasma deposition on the axis, explicit B⊥ solve.
- C++17/Kokkos (OpenMP, CUDA, HIP), MPI pipelining along ξ; benchmarked against HiPACE++ on the AWAKE self-modulation case (CPU and GPU).
- Laser envelope solver, field and impact ionization, trapping of plasma electrons into beams (ionization / Trojan-horse injection), beam spin (Thomas–BMT), multiple Coulomb scattering, adaptive time step, two-stage runs, checkpoints, openPMD output, a browser GUI.

**ParaView: openPMD fields on the non-uniform grid** (new)
`openPMDRectilinearReader.py` (attached) is a ParaView plugin that reads openPMD meshes with explicit, non-uniform coordinates — QUARZ's native output (`output.openpmd_grid = native`), GEM-PIC-RZ, and the rectilinear meshes proposed for openPMD 2.0. In ParaView (5.10 or newer, with `numpy` and `openpmd_api` in its Python): *Tools → Manage Plugins → Load New…*, select the file, then open a `.pmd` file and choose **openPMD Reader (rectilinear meshes)**. `quarz_paraview_samples.zip` contains small test files. Details: [`tools/paraview/README.md`](https://github.com/AlexMPukhov/QUARZ/blob/main/tools/paraview/README.md). Feedback welcome (issues).
